# Quản lý dự án (PM)

| File | Nội dung | Skill / lệnh |
|---|---|---|
| `project-plan.md` | Định hướng scope, estimate toàn bộ target scope, ưu tiên, WBS, thứ tự, phụ thuộc, schedule, phân bổ nguồn lực, team responsibilities (RACI), scope điều chỉnh/defer | `pm-project-plan` · `/pm-plan` |
| `stakeholder-register.md` | Stakeholder register | `pm-project-plan` · `/pm-plan stakeholders` |
| `raid-log.md` | RAID log (Risk / Assumption / Issue / Decision) | `pm-raid-log` · `/pm-raid` |
| `decision-log.md` | Decision log kèm lý do (gồm quyết định gate, CR) | `pm-raid-log` · `/pm-raid decision` |
| `tracking.md` | Bảng tracking: planned / completed / in-progress / deferred | `pm-status-tracking` · `/pm-track` |
| `status/STATUS-<ngày>.md` | Báo cáo health check và corrective actions | `pm-status-tracking` · `/pm-track` |

Plan baseline (v1.0.0) chốt ở gate G2 cùng design baseline. Thay đổi baseline kế hoạch → ghi DEC-xxx và nâng version.
